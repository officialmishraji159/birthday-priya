BIRTHDAY QUEST — PRIYA

Files:
- index.html
- assets/ (your uploaded photos)

How to use:
1. Keep index.html and the assets folder together.
2. Open index.html in a browser to test it.
3. To share it with Priya as a link, upload the whole birthday_quest_priya folder to a static website host.
4. After you have the public link, create a QR code for that link and print/send it.

Important:
- The game is designed for mobile.
- The clues use the details you provided.
- The final message is your supplied message.
